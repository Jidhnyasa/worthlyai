# Worthly AI — Chrome Extension (v1)

Floating badge on Amazon product pages that logs the ASIN on click.
The full verdict modal (Prompt 2) is not yet implemented.

## Setup

```bash
cd extension
npm install
npm run build
```

`npm run build` automatically generates the placeholder icons before building.
To regenerate icons without a full build: `npm run icons`.

## Loading in Chrome

1. Open `chrome://extensions`
2. Toggle **Developer mode** on (top-right)
3. Click **Load unpacked**
4. Select the `extension/dist` folder

## Testing

Visit any Amazon product page whose URL contains `/dp/` followed by a 10-character ASIN
(e.g. `https://www.amazon.com/dp/B09G9FPHY6`).

Look for the **Worthly floating badge** in the bottom-right corner of the page.
Clicking it currently only logs to the DevTools console:

```
[Worthly] badge clicked, ASIN: B09G9FPHY6
```

The verdict modal (API call + result card) is coming in v2.

## Notes

- Icons in `public/` are generated by `scripts/generate-icons.mjs` using `sharp`.
  Before submitting to the Chrome Web Store, replace them with properly designed
  256px+ assets — the generated ones are adequate for local development only.
- If `npm run build` fails with a Vite 5 compatibility error from `@crxjs/vite-plugin`,
  pin `"vite": "^4.5.3"` in `package.json` and re-run `npm install`.
